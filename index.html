📖 功能使用说明
✅打卡功能▶
添加打卡点右下角 + 号。可设置分类、图标、时间、每日重复或指定日期。
打卡/完成点右侧圆圈即完成打卡；再点一次可取消。
长按操作长按任意打卡项可快速「编辑」或「删除」，不用点进去。
批量添加新建打卡时点右上角「批量」，每行一条，支持智能日期：如「明天 早上8点 晨跑」「8月15日 看牙医」「周五 下午3点 开会」，自动识别日期和时间。
多选批量排版栏点「多选」，可全选后一键打卡、取消、开/关提醒、批量删除。
计时功能未完成的打卡项左侧有时钟按钮 ⏱，点它开始计时，屏幕下方浮动条实时显示，结束后记录「几点到几点 + 用时」。
详细记录添加打卡时开启「详细数值记录」，可记录数值如热量、页数、金额等，支持自动求和。
四种排版列表 / 宫格 / 时间轴 / 卡片，右上角风格按钮可切换配色风格。
查看某天顶部日历条可左右滑动，点选日期可查看/补卡过去或未来的打卡。
📋备忘功能▶
添加备忘切到「备忘」页点 + 号，分本周 / 本月 / 临时三类。
长按操作长按备忘可编辑或删除。
批量添加添加弹窗右上角「批量」，每行一条，自动去掉序号（1. 2、 - 等前缀）。
智能安排点备忘右侧 ⭐ 按钮，系统分析未来14天任务量，推荐最轻松的日期，一键转为那天的打卡项。
安排到今日点 📅 按钮直接把备忘安排到今天打卡。
👥多人记录（切换人选）▶
用途可以帮家人/朋友分别记录专属打卡和备忘，比如给宝宝记录喝奶、给爸妈记录吃药。
添加人物顶部人名条最右侧「＋」，输入名字即可。
切换点人名切换到对应人的专属记录；点「全部」进入全员总览页——整页按人分组展示所有人的今日打卡和待办备忘，可直接点圆圈替任何人打卡/完成。
长按人名长按人名可修改名字或删除该人物（删除会连带删除其打卡和备忘，请谨慎）。
🌈大小事记录▶
发布动态底栏切到「大小事记录」，点封面上的 ＋ 发布文字+图片动态，像朋友圈一样。
个人主页点头像可从相册上传头像，点封面 📷 换封面图，点头像旁的名字和下方签名可修改。
互动动态可点赞；再点一次取消。
💾数据与备份▶
一键备份设置 → 数据备份与恢复 → 一键备份，导出 JSON 文件保存。
恢复数据在任意设备选「恢复数据」导入备份文件即可完整还原（换手机/换电脑就用这个）。
数据安全数据只存在本机浏览器里，清除浏览器缓存会丢失，请养成定期备份习惯。
当APP用手机浏览器打开菜单选「添加到主屏幕」，即可像APP一样全屏使用。
